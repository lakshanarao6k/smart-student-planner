# Smart Student Planner

A modern student productivity web application designed to help students organize their academic activities in one place.

## 📌 Project Overview

Smart Student Planner is a web-based student productivity application that helps students manage assignments, classes, study sessions, exams, daily tasks, reminders, and overall progress.

The application provides a simple and user-friendly dashboard so students can easily keep track of their academic responsibilities.

## ✨ Features

- 🏠 Dashboard with an overview of academic activities
- 📅 Timetable management
- 📝 Assignment management
- 📚 Study session planner
- 🧪 Exam schedule management
- ✅ Daily task management
- 📊 Progress tracking
- 🔔 Reminder management
- 💾 Data stored using browser localStorage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Git & GitHub

## ⚙️ How It Works

Users can add their academic information through the different sections of the application.

The application stores the information using browser localStorage, allowing the data to remain available when the user refreshes or reopens the application in the same browser.

The dashboard automatically displays important information such as pending assignments, pending tasks, upcoming exams, study sessions, reminders, and overall completion progress.
